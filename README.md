# Fireworks AI Buildathon: Invoice Reconciliation

Project for **Fireworks: Deploy (with Microsoft and NVIDIA)**, November 2, 2026, San Francisco.
Event resources: https://hackersquad.io/events/fireworks-deploy-with-microsoft-nvidia/resources

## Event goal

Build an open-model system for a task that matters. Compare it against a frontier baseline. Measure gains in quality, cost, or latency.

**Goal: beat the frontier on your chosen task.**

## Five steps to a strong submission

1. **Create your evaluation.** Choose a useful task, held-out cases, and a success metric.
2. **Establish the frontier baseline.** Run a frontier model on your eval. Save its score.
3. **Engineer your system.** Build an open-model harness. Fine-tuning is optional.
4. **Rerun the same evaluation.** Use the same held-out cases and scoring.
5. **Show the before and after.** Report both scores, the gain, and reproducible evidence.
